Settings

Checked: Extension ONLY runs on sites in the Allowed Sites list below. Whitelist authorization is independent from Remembered Settings, so you can allow a site without sharing its saved volume between tabs. Enabling whitelist mode archives your current blocklist so it can be restored later.
Unchecked: Extension runs everywhere EXCEPT sites in the Blocked Sites list below.

Blocked Sites

Optional path: the list is a blocklist normally and an allow-list in Whitelist Mode. A path scopes the entry (e.g. example.com/videos); * matches within a path segment. Without a path, the whole site including subdomains is matched. Press Enter to add.

Remembered Settings

Manage saved volume, mono, and mute per site or URL path. A path such as example.com/videos applies to that path and its descendants; * can match within a path segment. Queries are ignored by normal Remember behavior, but a manually entered URL such as youtube.com/watch?v=abc creates an exact query-scoped profile (and ?v=* may be used as a query wildcard). These audio settings are independent from site access and debug overrides.

Site Debug Overrides

Persist DRM, CORS, debug highlight, and HTML media routing overrides independently from Remembered Settings. Turning Remember off in the popup will not remove these overrides.

Normalizer

Configure the real-time automatic gain controller and safety limiter. The popup's Normalize toggle is remembered separately per site/path from volume, mono, and mute.
Defaults: −16 dBFS RMS target, +12 dB maximum boost, −1 dBFS ceiling, 600 ms response. The limiter also protects routed manual boosts from digital clipping.
